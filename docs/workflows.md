# Project and task workflows

This guide describes the main actions in TickTask full mode.

## Select or create a project

1. Start the application with `uv run ticktask`.
2. Select an existing project, or enter a new project name.
3. Press `Enter` or select **Continue**.

The application activates the selected project and opens the main screen.

## Create a task

1. Open the main screen for an active project.
2. Press `t`.
3. Enter the task description.
4. Set the priority, completed state, and archived state as required.
5. Press `Enter` to save the task.

The description can contain up to 255 characters.

## Edit a task

1. Open the main screen for an active project.
2. Use `Up` and `Down` to select a task in the visible task list.
3. Press `Enter`.
4. Change the task fields.
5. Press `Enter` to save the task.

## Set task priority

Use the priority field in the task form. You can also use these keys in the task form:

- `l`: low
- `m`: medium
- `h`: high

## Complete or archive a task

Use the task form to change the completed or archived state.

- Press `c` to change the completed state.
- Press `a` to change the archived state.

Completed and archived tasks can affect the visible task list on the main screen.

## View all tasks

1. Open the main screen for an active project.
2. Press `v`.

The all-tasks screen shows active, completed, and archived tasks for the current project. The screen is read only.

Press `Esc` or `b` to return to the main screen.

## Change the active project

1. Open the main screen for an active project.
2. Press `p`.

The application pauses timer activity, resets the current interval, clears the current project state, and opens the project selection screen.
