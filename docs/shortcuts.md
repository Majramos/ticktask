# Keyboard shortcuts

## Timer controls

These controls work on the main screen and on the Pomodoro-only screen.

| Key | Action |
| --- | --- |
| `Space` | Start or pause the current timer. |
| `Right` | Move to the next timer. |
| `r` | Restart the current timer. |
| `a` | Turn automatic start for the next timer on or off. |
| `q` | Quit the application. |

## Default timer sequence

The default sequence contains these intervals:

1. Focus: 25 minutes
2. Short break: 5 minutes
3. Focus: 25 minutes
4. Short break: 5 minutes
5. Focus: 25 minutes
6. Long break: 15 minutes

When a timer ends, the application plays a bell. If automatic start is off, the application pauses after the interval changes.

## Main screen

These controls work when a project is active in full mode.

| Key | Action |
| --- | --- |
| `t` | Open the task form for a new task. |
| `Up` | Select the previous task in the visible task list. |
| `Down` | Select the next task in the visible task list. |
| `Enter` | Edit the selected task. |
| `v` | Open the all-tasks screen. |
| `p` | Change the active project. |

When you change the project, the application pauses timer activity, resets the current interval, and clears the active project state.

## All-tasks screen

| Key | Action |
| --- | --- |
| `Esc` | Return to the main screen. |
| `b` | Return to the main screen. |

## Project selection screen

| Key | Action |
| --- | --- |
| `Enter` | Continue with the selected project or create a new project. |

Use the existing project list or enter a new project name. If you enter a new project name, the application creates that project.

## Task form

| Key | Action |
| --- | --- |
| `Enter` | Save the task. |
| `Shift+Enter` | Insert a new line in the task description. |
| `Esc` | Cancel the form. |
| `l` | Set the priority to low. |
| `m` | Set the priority to medium. |
| `h` | Set the priority to high. |
| `c` | Change the completed state. |
| `a` | Change the archived state. |
